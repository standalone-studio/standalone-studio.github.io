# Paper Ecosystem Website

Repository ini berisi situs statis untuk Paper Ecosystem, termasuk halaman utama, Apps, Store, Support, dan sumber daya terkait.

## Fitur & Optimalisasi Terbaru (Audit 2026)
- **Desain Responsif & Premium**: Tema "Liquid Glass" yang konsisten di seluruh halaman, termasuk halaman legal.
- **SEO & Social Sharing**: Implementasi lengkap OpenGraph dan Twitter Cards untuk visibilitas maksimal.
- **Aksesibilitas (A11y)**: Atribut ARIA lengkap untuk navigasi dan komponen interaktif.
- **Performa Tinggi**: Optimasi pemuatan gambar dengan `loading="lazy"` dan `decoding="async"`.
- **Keamanan**: Content Security Policy (CSP) dan X-Frame-Options terkonfigurasi.

## Struktur Proyek
- `/assets`: Ikon, screenshot, dan aset gambar.
- `/css`: Stylesheet utama (`styles.css`).
- `/js`: Logika interaktif (`app.js`).
- `/paperleaf`: Halaman khusus produk Paperleaf dan dokumen legal.

## Pengembangan
1. Clone repositori.
2. Buka file di direktori `dev` dan edit HTML/CSS/JS sesuai kebutuhan.
3. Jalankan linting bila diperlukan.

## Deploy
Situs ini dihosting di GitHub Pages. Pastikan file `CNAME` ada untuk domain khusus.
