# Paper Ecosystem Website

Repository ini berisi situs statis untuk Paper Ecosystem, termasuk halaman utama, Apps, Store, Support, dan sumber daya terkait.

## Fitur
- Desain responsif dengan CSS modern.
- Navigasi interaktif, panel pencarian, dan modal detail aplikasi menggunakan JavaScript.
- Tag meta SEO, atribut bahasa, dan pertimbangan aksesibilitas.
- Content Security Policy (CSP) diterapkan via meta tag.
- Gambar teroptimasi (WebP) untuk loading cepat.

## Pengembangan
1. Clone repositori.
2. Buka file di direktori `dev` dan edit HTML/CSS/JS sesuai kebutuhan.
3. Jalankan `npm install` (untuk linting CI) dan `npm run lint` secara lokal bila ingin menguji konfigurasi lint.

## Deploy
Situs ini dihosting di GitHub Pages. Pastikan file `CNAME` ada untuk domain khusus.
